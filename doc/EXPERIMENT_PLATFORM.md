# 实验平台

目标是用已验证的链路组件快速搭实验，在同一组输入和传播条件下比较方法，并保留复跑所需的版本和配置。先服务于 NTN 波形与接收算法研究。

Alan 在此 WSL 环境下每次开始 Codex 任务时，先读取这份文档。仅在通信仿真及相关研究任务中应用下文的实验约定。

每次准备新实验时，先确定研究假设、主指标和对照，复用现有项目或链路工具箱能满足的部分。当计算、边界或信息假设会改变结论时，用最小模型验证。把正式研究结论限定在已核验的配置和信息条件内。

| 来源 | 首版用途 |
| --- | --- |
| `ntn_channel_sim` | 从动态星历快照取得公共多普勒和可见性 |
| `waveformDesign` | 生成既有 OFDM 波形，通过现有入口调用 OpenNTN 和 Sionna |
| WSL 本地 OpenNTN 源码 | 通过现有 `legacy` 后端复现旧版链路，独立保存运行记录 |
| `Experiment_Platform` | 调用两端的 Pixi 入口，核对单位和结果，记录运行信息 |

## 首版实验

1. `src/experiment_platform/experiments/siso_link.py` 是 SISO 接入实验入口。它接收两个项目根路径和场景配置，调用各自锁定的 Pixi 环境。参见 [运行命令](../README.md)。上游代码及其运行记录由原项目管理。
2. 在指定仿真时间查询一个可见的星历快照。核对载频一致、传播时延导数与公共多普勒的符号关系。把该带符号的 Hz 值传给 `waveformDesign` 已有的 OpenNTN 2.1 接口，在短帧内按常值施加一次。波形采样率由波形配置指定，首版只传递几何量。绝对路径时延作为记录，基带沿用 OpenNTN 相对时延和首抽头时间基准。
3. 按同一信道与种子运行现有两种 OFDM。核查多普勒传参、有效配置、输出长度和抽头时间原点，并做同种子复验。首版验收只针对链路接入，原始误符号数属于均衡前诊断。研究星历辅助收益时另行建立有误差的辅助信息与同资源基线。
4. 每次运行在 `runs/<UTC时间戳>_<唯一后缀>/result.json` 保存有效配置、种子、输入哈希、几何与输出摘要，以及各检出目录的版本和工作区状态。`source_has_local_changes: true` 表示源代码包含本地改动，按探索性运行处理。能取得实际执行版本和输入后，再登记正式可复现结果。

通过 `--openntn-root` 选择 WSL 内的 OpenNTN 源码目录。旧版后端使用自身的卫星模型，实验记录独立标为历史复现检查。星历驱动运行使用支持有符号频移输入的 OpenNTN 2.1 后端。接入其他已有开源项目时，先检查它能补充哪个实验能力及其可验证的接口，再登记源码版号和依赖环境。

## 依赖与已核查状态

- 两个上游由调用方提供本地检出及其 Pixi 环境。`waveformDesign` 的 GitHub 仓库访问受限，`ntn_channel_sim` 当前没有配置远端。公开仓库用户需要自行取得依赖。公开与本地依赖的说明以 README 为准。
- 已通过一次临时跨项目验证。将 NTN 动态星历第 1 秒的公共多普勒 `+39567.980907 Hz` 传入 `waveformDesign` 的 CPU 链路，与传播时延有限差分推导值相差约 `0.000029 Hz`。OpenNTN 2.1.0 与 Sionna 2.0.1 在 TDL-A 下，两个波形各由 432 个发射采样得到 445 个传播后采样，抽头索引为 `-6` 至 `7`，同种子复验通过。正式验证以首版入口保存的记录为准。
